# Connect Four

A Connect Four game built with React, TypeScript, and Tailwind CSS. Features an AI opponent powered by Monte Carlo Tree Search (MCTS) with adjustable difficulty levels.

## Tech Stack

- React 19
- TypeScript 5.8
- Tailwind CSS 4
- Vite 6

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start the development server
- `npm run build` - Type-check and build for production
- `npm run preview` - Preview the production build
